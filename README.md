# Codex Themes Toolkit

A standalone TypeScript toolkit that turns raw theme palettes (for example `.itermcolors`) into Codex-compatible JSON presets.

- [Installation](#installation)
- [Usage](#usage)
- [Preset Source](#preset-source)
- [Screenshots](#screenshots)

## Installation

```bash
pnpm install
```

## Usage

```bash
# convert only
pnpm convert

# normalize codeThemeId values
pnpm rescore

# run resolver smoke test
pnpm test

# run full pipeline (convert + rescore + test)
pnpm generate
```

## Preset Source

Themes are based on: [mbadolato/iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes)
